QuickView Privacy Policy

Publisher: Vivor Loong · Store ID: 9N1D85F032CC · Last Updated: 2026-11-16

1. Overview & Local-First Processing

QuickView ("the Application") is a local, high-performance image viewer for Windows. QuickView does not collect, store, sell, or transmit personal information, usage telemetry, analytics, or advertising identifiers. All image decoding, rendering, color management, metadata inspection, and rating/editing operations are performed strictly on your local device.

2. File System & Local Configuration

  • QuickView only reads and writes files or folders that you explicitly open, edit, export, or delete.
  • Application preferences, custom themes, and configuration files (such as QuickView.ini and ai_actions.json) are stored locally in your user AppData / package container storage.

3. Optional Network Features (User-Initiated Only)

  • Super-Resolution Model Weights: When you explicitly click to download optional neural network weights (.bin / .param data files) in Settings, QuickView fetches those public read-only model files from our GitHub Pages CDN and stores them locally under your AppData folder.
  • AI Command Palette (BYOK): AI features are strictly opt-in. If you choose to configure your own third-party API key (encrypted locally via Windows DPAPI) and manually invoke an AI action, the selected image region and prompt are sent directly from your device to the third-party AI provider endpoint you configured. Your data is governed by that provider's privacy policy. QuickView operates no intermediate proxy server.
  • Application Updates (Microsoft Store): The Microsoft Store edition receives updates exclusively through the Microsoft Store infrastructure and never contacts third-party update servers.

4. Contact & Support

If you have any questions about this privacy policy, please open an issue at: https://github.com/justnullname/QuickView/issues.

QuickView 隐私政策

发布者：Vivor Loong · Store ID：9N1D85F032CC · 更新日期：2026-11-16

1. 总则与本地优先原则

QuickView（以下简称“本应用”）是一款面向 Windows 平台的本地高性能图像查看器。 本应用不会收集、存储、出售或向开发者服务器传输任何个人身份信息、使用遥测数据、行为分析或广告标识符。 所有图像解码、渲染、色彩管理、元数据查看以及星级/编辑操作均完全在您的本地设备上完成。

2. 文件系统与本地配置存储

  • 本应用仅访问您主动打开、浏览、编辑、导出或删除的本地文件及目录。
  • 应用偏好设置、主题配置与快捷命令配置（如 QuickView.ini 与 ai_actions.json）均仅保存在您本机的应用隔离数据目录中。

3. 可选联网功能（仅由用户主动触发）

  • 超分辨率模型权重下载：当您在设置中主动点击下载可选的神经网络模型权重（.bin / .param 纯数据文件）时，本应用会从 GitHub Pages 静态分发节点下载公开模型文件并保存至本地 AppData 目录。
  • AI 命令面板（自带 API Key）：AI 功能默认关闭且需您主动配置自己的第三方 API Key（使用 Windows DPAPI 在本地加密存储）。仅当您手动触发 AI 操作时，当前图像与提示词会由您的设备直接发送至您所配置的第三方 AI 服务接口，并受该服务商隐私条款约束；开发者不设任何中转服务器。
  • 应用更新（Microsoft Store）：Microsoft Store 版本的应用更新完全由 Microsoft Store 系统托管，不会向第三方更新服务器发起检查或下载。

4. 联系方式

如对本隐私政策有任何疑问，请通过 GitHub Issues 与我们联系： https://github.com/justnullname/QuickView/issues。
